# Dough Hydration

DoughHydration is a simple dough hydration calculator, created in SwiftUI, for customising flour, water, and hydration percentages for various dough recipes. It uses interactive scales for fine-tuning dough measurements, as well as customisable presets for popular dough types.

## Features

- Flour, Water, and Hydration: adjust interactive scale views to set exact measurements for flour and water, or set the desired hydration percentage and automatically update the rest.
- Preset Recipes: Quickly access and apply preset measurements for common recipes like Sandwich Bread, Pizza, Baguette, Bagels, and Focaccia.
- Customisable Preset Selection: Activate or deactivate which presets show up the quick-select bar.
- Imperial & Metric Units: Toggle between metric and imperial units for flour and water measurements.
- Haptic Feedback: Tactile feedback while adjusting values.
- Settings Panel: Control the display of presets and unit preferences.

# Getting Started

## Requirements

- Xcode 15 or later (or your current version)
- iOS 17.0+ (or your current deployment target)
- Swift 5.9+

## Installation

1. Clone this repository:

```
git clone https://github.com/rshortall/DoughHydration.git
```
3. Open DoughHydration.xcodeproj in Xcode.
4. Build and run on a simulator or device.

## Usage

1. Open the app and use the sliders to adjust flour, water, or hydration percentage.
2. Tap a preset to instantly apply its measurements.
3. Use the checklist button to manage which presets appear on your main screen.
4. Access settings via the gear icon to enable/disable presets or toggle between metric/imperial units.
